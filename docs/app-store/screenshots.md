# Screenshot direction: a little bookshop, alive

Use genuine captures of the current release candidate, framed by parchment, forest-green serif headlines and the existing storyteller illustrations. Keep the interface large enough to understand at thumbnail size. This is a design hypothesis; conversion improvements must be measured, not promised.

The first three images sell the core reading experience. Characters add personality without hiding the product. Use one idea per image, a short headline above the screen, consistent margins and restrained decoration. Do not generate replacement UI or fabricate chat responses, progress or purchase success. Use a test profile with actual interactions; omit personal information.

## Capture and export

- Required iPhone target for this submission: **6.5-inch Display**, as requested by Matthew. Use **1242 × 2688 pixels portrait** consistently for the final set; Apple also accepts 1284 × 2778 in this group. Capture the matching simulator layout, or compose genuine app captures proportionally on the target canvas. Do not stretch screenshots or upload the existing 1260 × 2736 iPhone Air captures directly into this slot.
- iPad is enabled in the project: capture its real layout separately, at 2064 × 2752 or 2048 × 2732 portrait. Never stretch the phone UI into an iPad image.
- Export flattened PNG or JPEG at an accepted size. Preserve aspect ratios. Use consistent status-bar appearance and clean test data; no debugging banners, keyboards hiding key controls, AssistiveTouch overlays or personal notifications.
- Keep source captures separate from composed upload images. Suggested paths when produced: `screenshots/source/iphone/`, `screenshots/source/ipad/`, `screenshots/upload/en-GB/iphone/`, `screenshots/upload/en-GB/ipad/`. Use the actual listing locale if different.
- Name files `01-library.png` through `06-chat.png`. Record build, device, locale and capture date with each set. Recapture after UI changes.
- Inspect every export at full resolution and at small App Store preview size. Check text clipping, theme consistency, readable English/Spanish and honest feature/purchase claims.
